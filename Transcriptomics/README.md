The code in this folder is used to analyze the counts from the RNA-seq data, which can be found in the GEO database here: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE185914

* `src/` folder contains all of the scripts for processing the transcriptomics
* `analysis/` folder contains all of the output files from each of the scripts in src
* `data/` folder contains any necessary data files for running the scripts

Code to run the enrichment analysis can be found in the 'Transcriptomics/analysis
/enrichment/' folder. Run enrich_calls.txt in the terminal in the same directory as all of the files in the enrichment folder to produce results
